# موقفي المالي — مشروع Android

هذا مشروع مصدر لتطبيق Android باسم «موقفي المالي»، وليس APK جاهزاً.

## طريقة إنشاء APK
1. ثبّت Android Studio على كمبيوتر.
2. افتح هذا المجلد في Android Studio.
3. اسمح بمزامنة Gradle وتنزيل Android SDK 35.
4. من القائمة اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
5. بعد نجاح البناء ستجد APK داخل app/build/outputs/apk/debug/app-debug.apk.
6. انقل الملف إلى هاتف Android وثبّته مع السماح بالتثبيت من هذا المصدر.

## الموجود في النسخة الحالية
- دخل شهري ودخل إضافي.
- مصروفات يومية وتصنيفات.
- إجماليات يومية وشهرية وحساب المتبقي.
- إضافة الأقساط وجدولة تذكيرات محلية.
- تقارير شهرية وتصدير CSV.
- نسخ احتياطي واستعادة JSON.

## تنبيهات وقيود النسخة الأولية
- يلزم اختبار التنبيهات على الهاتف بعد تثبيت APK والسماح بالإشعارات.
- بيانات التطبيق محفوظة محلياً داخل مساحة التطبيق.
- القفل برقم سري في هذه النسخة ليس تشفيراً احترافياً.
- يجب تطوير سجل سداد الأقساط قبل اعتماد الرصيد المتبقي باعتباره شاملاً للدفعات.

## البناء السحابي من الهاتف
أضيف ملف GitHub Actions في `.github/workflows/build.yml`. بعد رفع محتويات المشروع إلى مستودع GitHub عام أو خاص:
- يشتغل البناء تلقائياً عند الدفع إلى فرع main، أو يمكن تشغيله يدوياً من Actions.
- عند نجاح البناء يظهر Artifact باسم `my-financial-position-apk`.
- نزّل الـ Artifact واستخرج منه `app-debug.apk` ثم افتحه على هاتف Android.
